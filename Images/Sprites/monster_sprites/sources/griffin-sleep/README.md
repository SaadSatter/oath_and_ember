# Griffin sleeping and standing

User-supplied PixelLab export `Images/Sprites/Griffin/Griffin-Sleeping`, supplied October 16, 2026; full original metadata and frames preserved in `pixellab-export`.

`scripts/import-griffin-sleep.py` packs eight native sleeping rotations followed by ten south standing-up frames into 176px cells. Transparent padding aligns the base at (88,130), using native anchors (64,106) for sleep and (74,136) for waking. No resampling or recoloring; nearest-neighbor rendering. The sleep direction uses the same eight-direction ordering as the mouth artwork. The south wake sequence plays once over the authoritative one-second WAKING phase.
