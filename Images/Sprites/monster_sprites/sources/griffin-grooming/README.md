# Griffin mirror and haircut sequence

User-supplied PixelLab artwork, October 16, 2026. Mirror export found at `Images/Sprites/Griffin/A_standing_Griffin_biped-Pretending_to_check` after the supplied Downloads path had moved. Shears export recovered from the user-supplied `Downloads/A_standing_Griffin_biped-Holding_shears_to_hi.zip`. Both complete original exports and the shears ZIP are preserved here.

`scripts/import-griffin-grooming.py` packs the transparent source PNG frames: south mirror (0–8), north mirror (9–17), north shears (18–26). Native pixels, transparent centering in 176px cells, no resampling or recoloring. The GIF previews have green backgrounds, so original transparent export frames are preferred. Client uses a fixed (88,132) base anchor. South and north checks run for 2.7 seconds each; shears play once over 0.9 seconds, then hold their final pose.
