# Ruin pillar

User-supplied PixelLab export from `Images/Sprites/A_tall_pillar_from_the_ruins`, supplied October 16, 2026. The complete export and metadata are preserved in `pixellab-export`.

`scripts/import-griffin-pillars.py` packs the unchanged standing image and nine collapse frames into native 160px cells. The settled rubble frame retains the lower debris from the final collapse frame, removing the still airborne shaft. No resampling or palette changes. Client anchor (80,128) aligns the base to the existing authoritative pillar footprint; collisions and Griffin stun behavior are unchanged.
