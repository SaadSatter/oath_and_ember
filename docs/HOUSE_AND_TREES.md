# House starting area and forest trees

Start normal play with `npm run dev` and open http://localhost:5173 in two browser sessions. Create a fresh room, choose Sieg/Coco and ready both. Normal rooms now begin at MAIN_HOUSE. Follow the path east and press E by the EXIT marker to move both heroes into FOREST_RUINS. The existing puzzle/airship/boss progression continues. `npm run enemy:encounter` deliberately remains a forest-only combat test and bypasses this opening area.

The house exterior uses the supplied `Images/Sprites/Main House/Tiled_files/Exterior.tmx` and its matching Tiled_files PNGs. The similarly named PNG/exterior.png has different dimensions and is not substituted. `scripts/import-house-map.py` converts the authored infinite chunks into a finite27×20 map, preserving layers and flip flags. Source files are untouched. Runtime tiles remain16px, rendered at integer2× scale in an864×640 world. The landscape opening camera uses .5 zoom and centers the grounds; portrait uses1× following to keep the playable area readable; together these preserve source tile pixel structure at logical resolution. Other scenes retain their existing camera scale. Resize continues through the existing responsive renderer.

Original trees in the exterior map are explicitly removed from the verified source tile regions and replaced at eight ground positions. The existing geometric trees throughout FOREST_RUINS are replaced at the same deterministic positions. Tree1/2/3 and Moss_tree1/2/3 come directly from `Images/Sprites/forest tree art/PNG/Assets_separately/Trees`. Each retains its original64px/128px transparent canvas and colors; verified trunk-base origins prevent floating caused by canvas padding. Airship scenes contain no tree placeholders and retain their current presentation. Tree canopies sort by ground position so heroes can pass in front/behind them.

House collision is explicitly authored in shared/maps.ts for the house/fence footprints and outer bounds, independently of rendered pixels; trees remain decorative and do not change forest movement/collision. No automatic collision extraction, image generation or retired art workflow is used. Server-owned nearby E interaction chooses the transition, resets both heroes and spawns the existing four forest enemies. Clients share the same map/collision declaration for prediction and only render server scene state.

`docs/ENVIRONMENT_ASSET_PROVENANCE.json` records the exact map/source hashes and deterministic import operations. The supplied tree license notice is retained with runtime tree files. Original source packs and approved monster artwork remain unchanged.

QA: `PLAYWRIGHT_BROWSERS_PATH=/private/tmp/oath-ember-playwright node --import tsx scripts/house-environment-qa.ts qa/NEW_DIRECTORY` records two actual browser sessions, checks house→forest transition through ordinary browser input, and captures both clients at1920×1080,1440×900,390×844 and844×390. Native recordings are retained alongside screenshots and errors. Final evidence lives in `qa/house-environment-v4`. Prior capture attempts are retained. Runtime/HTTP errors fail QA; a missing browser favicon is excluded from gameplay resource failures.
