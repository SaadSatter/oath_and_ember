# Authoritative forest enemy encounter

Run `npm run enemy:encounter` (builds and starts the encounter server), then open http://localhost:3017 in two independent browser sessions. Create/join one room, select Sieg/Coco and ready both. This server-selected validation preset opens the existing forest puzzle gates and starts heroes in the middle clearing. Normal `npm run dev` retains puzzle progression and the same four enemies. WASD/arrows move, J attacks/casts, K defends; unlock Guard/Ward through Skills first. F3 toggles tick/state/target/health diagnostics. The existing instant player respawn remains; encounter respawn returns to the middle clearing. No client outcome commands were added.

Definitions in `packages/shared/src/enemies.ts` own stats, behaviors, body sizes and sprite IDs. Instances hold type, maximum/current health, velocity, facing, target, state, attack sequence/start tick/locked facing, next attack tick and death tick. The server-only `enemySimulation.ts` advances IDLE → CHASE → ATTACK (windup) → CHASE/cooldown; lethal damage enters DEAD and the server removes the entity after 30 ticks. An attack locks its target/facing during windup; melee resolution checks living/connected target, range and walls again. Dead enemies cannot attack. Ties use stable ID order, and current targets are retained while within 30px of the nearest detectable living connected player.

Wisp retreats when closer than 155px, approaches beyond 250px, and attacks within the 155–250px band when line of sight is clear. It fires into the existing projectile stream with enemy faction, damage, radius and owner. Swept segment checks stop projectiles at world/puzzle walls; each projectile hits one opposing entity. It never damages allied enemies. Sieg's unchanged accepted sword (25 damage) and Heavy Break (40) strike nearby living enemies through `damageEnemy`; walls block enemy hits. Coco's accepted casts retain speed 420/lifetime1.6 and deal20 to enemies through the same path. Enemy attacks reuse existing player guard/ward damage reduction and respawn. No per-monster checks were added to player attack code.

Existing `game:snapshot` / `state:sync` carry the expanded enemy and projectile records at the existing 30Hz simulation /15Hz snapshot cadence. Both clients interpolate enemy positions with the existing100ms buffer; neither runs AI or enemy prediction. Animation uses authoritative velocity/facing/state and the unchanged approved contracts. Render interpolation can lag the latest authority position; equal video presentation timestamps are not synchronization evidence.

Approved monster atlases and original sources are preserved in `Images/Sprites/monster_sprites`. The game uses the unchanged runtime copies in `apps/client/public/assets/enemies`; hashes and original approvals are stored with the preserved designs. The multi-role art workflow, generation/provider tooling and publication commands have been removed. Mossling/Sentinel west continues to use the canonical east animation and runtime flipX; Wisp preserves its approved west frame selection.

Temporary presentation: melee attack windup holds the contact pose with a geometric orange range ring; Wisp retains its hover while winding up, with an orange ring and the existing ember projectile effect. No attack/death sprite art exists. Dead sprites hide immediately while authoritative DEAD records remain for one second before despawn. Future attack/death art requires an explicit art revision. Sentinel weight comes from slower movement, longer windup/cooldown and approved scale; its approved animation FPS remains unchanged.

Limitations: simple collision-aware pursuit slides against axis-aligned obstacles; there is no route planning, entity separation, advanced kiting or boss AI. Player respawn is immediate; no persistent player death state/revival was added. Damage and projectile collision preserve simple existing combat conventions rather than introducing a new hitbox system. Forest scenes remain art direction; the encounter uses the existing geometric map. No loot/XP/inventory or new artwork.
