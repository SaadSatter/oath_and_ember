# Fonts

`PressStart2P-Regular.ttf` — Press Start 2P, © 2012 The Press Start 2P Project
Authors (cody@zone38.net), licensed under the SIL Open Font License 1.1
(`PressStart2P-OFL.txt`). Downloaded unmodified from
https://github.com/google/fonts/tree/main/ofl/pressstart2p and self-hosted so
the dialogue box renders the same offline.

Every glyph outline sits on an exact 8-pixel em grid (125 of 1000 units), so
the font is only crisp at whole multiples of 8px. The dialogue box uses 16px:
each font pixel is exactly 2×2 CSS pixels. (Pixelify Sans was used briefly
but its outlines are not grid-aligned, so it blurred at every size.)
