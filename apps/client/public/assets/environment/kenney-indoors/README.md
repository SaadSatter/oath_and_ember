# Kenney Roguelike Indoors

Unmodified tilesheet from Kenney (https://kenney.nl/assets/roguelike-indoors).
License: CC0 1.0 Universal. See License.txt. Original archive, sample and preview
are preserved in Images/asset-sources/kenney-roguelike-indoors.
Tiles are 16x16 with a 1px gutter. Rectangular frames are selected at runtime
with nearest-neighbor filtering. Used for tables/seats on upper floors, the inn
and benches in the new settlements. LPC artwork retains its separate CC-BY-SA
license. New town layouts and stair decorations are original Oath and Ember work.
