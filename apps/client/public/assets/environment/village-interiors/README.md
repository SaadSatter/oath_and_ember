# Emberbrook Village interiors

Generated by `node scripts/build-village-interiors.mjs` (add `--preview <dir>`
for review renders with collision outlines). Do not hand-edit; change the room
layouts in the script and regenerate.

The room shells use the user-supplied main-house wall, floor and window sheets.
Furniture layers are named placement placeholders; the live renderer fills them
with unmodified LPC and Kenney frames. Furniture areas and explicit gameplay
footprints are authored in `scripts/village-room-layouts.mjs`, independently of
sprite padding. No source artwork is altered.

| Map | Village house |
| --- | --- |
| village_cottage.json | Hearthside Cottage (north-west house, the heroes' mother) |
| village_elder_house.json | Elder Bertram's House (south-west house) |
| village_apothecary.json | Brynn's Apothecary (large house) |

The script also writes the depth-sorting regions
(`apps/client/src/environment/villageInteriorRegions.json`) and the gameplay
data the server uses — room size, spawn, doorway, outside arrival and
collision footprints (`packages/shared/src/villageInteriors.json`).

## LPC presentation

The live village renderer replaces the base maps' furniture layers and wooden
floors with LPC artwork. See `../lpc-interiors/README.md` for sources, author
credits and CC-BY-SA 3.0 licensing. Native-resolution source sheets are retained.
The main house is unaffected. Doorways, room shells and gameplay collision still
come from the reviewed base layouts above.

After regenerating these layouts, also run
`node scripts/build-lpc-village-interiors.mjs` to regenerate the artwork placement
manifest. `node --import tsx scripts/qa-lpc-interiors.ts` renders all three homes
for both clients after a build.

The clean layout checks reserve windows and stair landings, keep all non-rug
furnishings separate, and verify every door/stair route is reachable. Use
`scripts/render-town-previews.ts` for full PNG overviews and paired floor images.
